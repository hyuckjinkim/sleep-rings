# 앱 이름 후보 검증

> 목적: Sleep Orbit 클론 앱의 스토어 제출용 이름 결정. "Sleep Orbit"(SMB Studio LLC, App Store/Google Play 등록 앱, 앱 내 100+ 사운드·17개 카테고리·바이노럴 3D 오디오 믹서)과 혼동되는 이름은 금지.
> 조사 방법: WebSearch로 (a) App Store/Google Play 동일·유사명 앱 존재 여부, (b) `"<이름>" trademark` 검색으로 상표 충돌 신호, (c) 기존 유명 제품과의 혼동 가능성을 확인. **USPTO 공식 데이터베이스(tmsearch.uspto.gov)는 이 조사 방식으로 직접 크롤링되지 않아 "등록 상표 없음"을 확정할 수는 없다** — 아래 판정은 일반 웹 검색 신호 기반이며, 최종 상표 확정은 스토어 제출 전 USPTO/특허청 공식 검색 및 변호사 검토가 필요하다.

## 원본 앱 확인

"Sleep Orbit: Relaxing 3D Sound / ASMR 3D Sounds"는 SMB Studio LLC가 App Store(id1215043393)와 Google Play(`net.sleeporbit`)에 등록한 실제 서비스 중인 앱이다. USPTO에서 "Sleep Orbit" 자체의 상표 등록 여부는 이번 웹 검색으로는 확인하지 못했다(공식 상표 데이터베이스 직접 조회 필요). 다만 상표 등록 여부와 무관하게 동일 카테고리(수면 사운드 믹서)에서 실제 서비스 중인 앱과의 명칭 혼동은 스토어 심사 반려·소비자 오인·잠재적 부정경쟁 소지가 있으므로 회피 대상으로 유지한다.

또한 조사 중 "Orbit"이 이완/명상/수면 앱 카테고리에서 이미 여러 번 재사용되는 단어라는 사실이 확인됐다: Sleep Orbit(원본), DreamMeORBIT(수면용 플라네타리움 앱), Calm Orbital(이완용 우주 테마 앱), Orbit Meditation: AI Sessions(명상 앱) 등. 즉 "Orbit"을 포함하는 한 원본과의 개별 충돌 외에도 카테고리 전반의 이름 혼잡도가 존재한다 — 이는 후보 판정에 공통 배경으로 반영했다.

## 최종 추천

### 1순위: **SleepRings**
- 원본 "Sleep Orbit"과 어순·구성 단어(Orbit)가 달라 직접적 명칭 혼동 위험이 8개 후보 중 가장 낮음.
- 동일 명칭의 경쟁 앱을 스토어에서 확인하지 못함.
- 앱의 실제 UI 은유(중심에서 뻗어나가는 동심원 = 볼륨 반경)와 이름이 자연스럽게 맞아떨어짐.
- 주의점: "Sleep Ring"류 수면 트래킹 웨어러블(SleepImage Ring, RingConn 등)과 카테고리를 오인할 소지가 있음 — 스토어 부제/설명에 "사운드 믹서" 성격을 명확히 표기해 완화 권장.

### 차선 1: **Drift Orbit**
- 원본과의 직접 연상 낮음. 기존 동일어 게임 2종(Orbit Drift, Orbital Drift)은 카테고리(액션 게임)가 달라 사용자 혼동 실질 위험은 낮으나, 단어 재배열형이라는 인상은 유의.

### 차선 2: **Lull Orbit**
- "Orbit"이 원본과 겹치지만 "Lull"은 원본과 어의적 유사성이 없음. 다만 "Lull" 브랜드 수면 사운드 앱이 이미 2개 이상 존재해 스토어 검색 혼선 가능성 있음. PLAN.md에 원 후보로 명시돼 있어 차선으로 유지.

### 배제 확정: Slumber Orbit, DreamOrbit, Luna Orbit, Calm Orbit, Nova Orbit
- DreamOrbit(동일 카테고리 근접 앱 DreamMeORBIT 실존), Slumber Orbit("SLUMBER" 등록 상표 + 동일 카테고리 앱), Calm Orbit(업계 1위 Calm.com 상표 충돌 위험), Luna Orbit("Luna" 수면 앱 카테고리 포화), Nova Orbit(대형 게임 프랜차이즈에 스토어 노출 잠식) — 순서와 무관하게 전부 회피 권장.

## 조사 한계 (명시)

- USPTO/특허청 공식 상표 데이터베이스를 직접 조회하지 않았다 — 이번 조사는 일반 웹 검색(WebSearch) 결과 기반이며, 등록 상표 유무를 법적으로 확정하지 못한다. 스토어 제출 전 `tmsearch.uspto.gov` 및 국내 특허청 키프리스(KIPRIS) 공식 검색, 필요시 변호사 검토를 권장.
- 앱스토어/구글플레이 전수 조사가 아닌 웹 검색 상위 노출 결과 기반이므로, 검색에 노출되지 않은 소규모/비영어권 앱과의 충돌은 발견하지 못했을 수 있다.
- 도메인 소유 여부는 조사하지 않았다.
