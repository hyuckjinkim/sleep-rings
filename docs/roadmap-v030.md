# SleepRings v0.3.0 로드맵 (R5 — 리서치 4종 종합)

> 2026-08-16 확정. 근거: `.omc/research/{community-needs, monetization, platform-capabilities, competitive-matrix}.md`
> 오너 방침: ① 사운드를 티어별 구분(무료/2천/5천/1만원) ② **무료에서 최대한 많이** ③ 플랜 미충족 사운드는 숨기지 말고 **비활성 노출** ④ 전면·보상형 영상 광고 금지, **배너만**(클릭 시 추가 수익) ⑤ 화면 5/10/30분 자동 꺼짐 ⑥ 사운드 아이콘화·배경 등 디자인 고도화

## 0. 리서치가 뒤집은 전제 3가지

| 전제 | 실제 | 대응 |
|---|---|---|
| "N분 후 화면을 끄면 된다" | iOS/Android 모두 **앱이 화면을 직접 끄는 API 없음**. wake-lock 해제도 사용자 OS 설정에 종속돼 시각 보장 불가 | **암전 오버레이(확정적) + wake-lock 해제(OLED 보조)** 병행 |
| "사운드 개수로 티어를 가른다" | 현 카탈로그 11종 — 개수로 가르면 무료가 빈약해져 방침②와 충돌 | **합성 사운드 8종 먼저 추가(→19종)** 후 개수 기반 티어링. 레이어/기능 축은 보조 |
| "10,000원 티어도 같이 출시" | 그 티어를 채울 콘텐츠(파일 음원)가 미확보 | **구조만 구현, 상품 등록은 콘텐츠 확보 후로 순연** |

## 1. 사운드 확장 (B1) — 합성 8종, 파일 불필요

R3 권고 Top 8, 전부 기존 `noise.ts` 프리미티브(필터·스웰·지터) 재사용 범위:

| # | 사운드 | 합성 레시피 | 난이도 |
|---|---|---|---|
| 1 | 캠프파이어 | 브라운 노이즈 + 임펄스 버스트(탁탁) | M |
| 2 | 선풍기/에어컨 험 | 로우패스 + 미세 스웰 (wind 변형) | S |
| 3 | 천둥 | 느린 로우패스 + 급격 엔벨로프 (rain 보조 레이어) | M |
| 4 | 시냇물(변형) | 기존 stream 파라미터 프리셋 | S |
| 5 | 우산 위 빗소리 | rain + 공명 레이어 | M |
| 6 | 로우파이 험/우주 앰비언스 | 좁은 로우패스 + 저역 사인 (binaural 로직 재사용) | S |
| 7 | 심장박동 | 저역 이중 사인(lub-dub) + 리듬 트리거 | M |
| 8 | 자궁 소리 | 강한 로우패스 + 심박 레이어 | M |

**제외**: 새소리(FM 처프 — 별도 서브시스템), 기차(리듬 튜닝 공수 과다). 모든 신규 사운드는 기존 `NATURE_TARGET_RMS` 정규화 규약을 따라 체감 음량을 맞춘다.

## 2. 플랜·티어 (B2) — "무료 최대 개방" 우선

카탈로그 확장(19종) 후 기준:

| 티어 | 사운드 | 기능 | 광고 |
|---|---|---|---|
| **무료** | 노이즈 4 + 자연음 4 + 신규 합성 중 4 = **12종(전체의 63%)** | 동시 레이어 3개, 프리셋 3슬롯 | 배너(비-재생 화면) |
| **2,000원** | + 신규 합성 나머지 4 = 16종 | 레이어 5개, 프리셋 10슬롯 | **제거** |
| **5,000원** | + 바이노럴 3 = **전 19종** | 레이어 무제한·프리셋 무제한, 볼륨커브/페이드 고급 컨트롤 | 제거 |
| **10,000원** | + 향후 파일 기반 프리미엄 라이브러리 우선 접근 | 전체 | 제거 |

- **비활성 노출 규칙**(방침③): 잠긴 사운드는 팔레트에 자물쇠 아이콘으로 계속 보이고, 탭하면 업그레이드 안내. 카테고리 탭에서도 숨기지 않는다.
- **레이어 제한 UX**: 한도 초과 시 배치를 거부하는 대신 "가장 오래된 오브를 대체할지" 또는 업그레이드 안내 — 야간 사용자가 막혔다고 느끼지 않게.
- **10,000원 티어**: `Plan` 타입·게이트 로직에는 포함하되 **스토어 상품 등록은 수동 단계 문서로 순연**(콘텐츠 미확보 상태로 판매 금지).
- **결제**: RevenueCat `purchases-capacitor` 권장(서버 없이 영수증 검증, MTR $2,500/월까지 무료). ⚠️ `@capacitor-community/in-app-purchases`는 **실존하지 않는 패키지**(2020년 제안 이슈뿐) — 검색 혼동 주의.

## 3. 배너 광고 (B4)

- 플러그인 1안 **Cap-go/capacitor-admob**(Capacitor 8 전용), 백업 `@capacitor-community/admob`.
- **배치 규칙(위반 시 계정 정지 리스크)**: 믹서 조작 화면·컨트롤 근접 배치 **금지**. 라이브러리/설정/프리셋 화면 하단에만. 야간 밝기 고려해 배너 영역도 다크 톤 유지.
- **필수 동반 작업**: iOS ATT 프롬프트 + `PrivacyInfo.xcprivacy`, Google UMP 동의 폼(EEA/UK 미연동 시 Limited Ads 강등), Data Safety/개인정보처리방침 갱신(광고 ID 수집으로 "수집 없음" 문구 수정 필요 — 현 정책 문서와 모순 발생).
- 광고 단위 ID는 **테스트 ID로 구현·검증**, 실 ID 발급은 수동 단계.

## 4. 화면 자동 꺼짐 (B3)

- **암전 오버레이**: 5/10/30분(+사용 안 함) 선택 → 무동작 N분 후 전체 화면 검정(#000, OLED 실절전) + 최소 힌트, **오디오는 계속 재생**. 탭/스와이프 시 즉시 복귀.
- **wake-lock 해제 병행**: 오버레이 진입 시 wake lock 해제해 OS 타임아웃도 걸리게. `@capacitor-community/keep-awake`는 Cap8 미지원 → **Cap-go 포크** 사용 또는 웹 Screen Wake Lock API 직접 사용.
- 슬립 타이머와 독립: 화면만 끄고 소리는 유지 ↔ 타이머는 소리를 끈다. UI에서 두 개념을 명확히 구분.
- R1 실증: 벤치마크 앱 리뷰에 *"어두운 화면에서 1분 뒤 (오디오가) 꺼진다"* 불만 — 암전 중 오디오 지속을 E2E로 반드시 검증.

## 5. 플랫폼 기능 (B3, 즉시 가능분만)

잠금화면 미디어 컨트롤(`@capgo/capacitor-media-session`), 햅틱(`@capacitor/haptics`), 화면 방향 잠금. **미루기**: 홈 위젯(네이티브 타겟 필요), Health 연동(권한·심사 부담 과다), 시스템 알람(공개 API 없음).

## 6. 디자인 고도화 (D1/D2)

- 사운드 **아이콘 세트**(design-lead 제작) → 오브·팔레트 칩에 적용. R4 지적 "노이즈 4종이 같은 hue라 구분 불가"의 근본 해결.
- **배경 레이어 보강**: 현재 사실상 단색 → 다층 그라데이션·미세 노이즈·궤도 발광. 저자극·60fps·`prefers-reduced-motion` 준수.
- 헤더 타이포 굵기 재검토(경쟁 앱은 얇거나 중간 — "차분함 신호").

## 7. 커뮤니티 니즈 반영 (R1 Top 10 중 채택분)

프리셋 export/import(JSON), 재생/정지 전환 페이드, 이명 친화 프리셋(브라운+저볼륨), volumeCurve 프리셋 다양화, 자연음 루프 크로스페이드 검증. **프리셋 저장 견고성**은 R1의 "8번째 믹스에서 데이터 손실" 리뷰를 근거로 QA 필수 항목에 추가.
