SleepRings("본 앱")는 사용자의 개인정보를 수집하지 않습니다.

## 수집하는 정보

없습니다. 본 앱은 회원가입, 로그인, 계정을 요구하지 않으며, 서버로 전송되는 사용자 데이터가 없습니다.

## 기기에 저장되는 정보

다음 정보는 오직 사용자의 기기 안에만(로컬 저장소) 저장되며, 외부로 전송되지 않습니다.

- 현재 믹스(배치한 소리의 위치·볼륨 등)
- 저장한 프리셋
- 언어·설정값

앱을 삭제하면 이 정보도 함께 삭제됩니다.

## 분석·광고 SDK

본 앱에는 분석(analytics), 광고, 트래킹 SDK가 포함되어 있지 않습니다. 사용자의 행동을 추적하거나 제3자와 데이터를 공유하지 않습니다.

## 네트워크 연결

본 앱은 오프라인에서도 동작합니다. 별도의 계정 서버나 API 호출이 없습니다.

## 아동의 개인정보

본 앱은 개인정보를 수집하지 않으므로 연령과 무관하게 별도로 수집·처리되는 아동 개인정보가 없습니다.

## 변경 고지

본 방침이 변경되는 경우 이 문서와 앱 스토어 등록 정보를 갱신합니다.
