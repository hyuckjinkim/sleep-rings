## 발견 상세 (백로그 ID 부여)

### CRITICAL
- **B1** [UX] 키보드 전용 조작 완전 불가(WCAG 2.1.1) — Orb: role=button+tabIndex인데 onKeyDown 없음, PaletteItem: pointer 핸들러만. Tab+Enter로 추가·조작 0건 실측
- **B2** [UX] 팔레트 탭만으로 추가 무반응 — 드래그 없이 탭하면 조용히 실패. 첫 사용자 최대 이탈 지점 (B1과 동일 지점 수정으로 해결)

### HIGH
- **B3** [기능] 슬립 타이머 자연 완료 후 "해제" 버튼 disabled — `disabled={!sleepEndsAt}`가 "타이머 없음"과 "막 끝남"을 구분 못함. v0.1.0 재관여 픽스의 미완결 지점
- **B4** [디자인] 터치 타겟 44px 미달 다수 — 언어 25px·타이머 24px·팔레트칩 32px·팝오버닫기 21px 실측
- **B5** [디자인] 중심 헤드가 🌙 이모지 — 콜드스타트 tofu 렌더 실재현, icon.svg와 불일치 → SVG 인라인 교체
- **B6** [디자인] 언어 전환 버튼 미스타일(브라우저 기본 흰 버튼)
- **B7** [UX] 실수 삭제 undo 없음 — 삭제존 드래그 즉시 영구 삭제
- **B8** [UX] 500ms 정지만으로 오토락 — 의도 구분 없음, 피드백 2px 아웃라인뿐
- **B9** [UX] 온보딩·제스처 힌트 전무 — 4대 제스처 발견 장치 0

### MEDIUM
- **B10** [기능] 휠 궤도 변형이 passive 리스너에서 preventDefault — 매 틱 콘솔 에러
- **B11** [UX] 삭제존 상시 노출(빈 상태에도) → 드래그 중만 표시
- **B12** [UX] 비활성 "해제" 대비 2.06:1 — 어두운 방에서 불가시
- **B13** [UX] OrbControls에 Escape/바깥클릭 닫기 없음
- **B14** [UX] aria-label 붙은 div에 role 없음 — 접근성 트리 미노출 실측
- **B15** [디자인] 삭제존 라벨 텍스트 선택 가능(user-select 누락)
- **B16** [디자인] 궤도 가이드 동심원(25/50/75/100%) 미구현 — visual-theme §4
- **B17** [기능] 타이머 완료 후 새 배치 시 오디오는 재개되나 sleeping 시각 상태 잔존
- **B18** [스토어] listing-ko "끊기지 않는 밤" — iOS 백그라운드 미검증 상태에서 과약속 → 문구 완화

### LOW
- **B19** 팔레트 가로스크롤 힌트 없음 · **B20** favicon이 icon.svg 미참조 · **B21** 포커스 링 토큰화 안 됨 · **B22** 태블릿+ 필드 420px 상한 여백 과다
